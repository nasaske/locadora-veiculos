Sobre

Front-end da Locadora de Veículos, feito para a atividade "Linkando API com Node.js e Bootstrap". As páginas são servidas por Node.js e consomem a API REST em C#/ASP.NET Core (Entity Framework Core + SQL Server) usando somente fetch.

Fotos dos veículos de exemplo: Wikimedia Commons (licenças livres).
